# 第一版服务器建议

建议起步：日本机房，2 vCPU / 4GB RAM / 80GB SSD，月付、可升级。模型通过 API 调用；这不是本地运行大模型的配置。预算允许可选择 4 vCPU / 8GB。

2026-09-09 本机正常运行快照：Genchi 容器合计约 1.1GB 内存，浏览器约 500MB、PostgreSQL 165MB、Next.js 89MB；这不是峰值或压力测试结果，不能据此承诺访问量或并发数。

4GB 起步时：浏览器同时抓取 1 个页面；采集 worker 并发 1–2；限制历史回放；生产构建在本地 / CI 完成后上传镜像；数据库、日志、原始页面与旧镜像设置保留策略，备份放在另一处。邮件使用正式投递服务，不在这台小机器上另建邮件服务器。生产环境不需要运行本地 Mailpit，Dashboard 可按需启动。

日本优先是针对日本票务站、作品官网和官推的来源构成；国内访客到日本的体验依赖云商线路，采购前从目标用户网络实测。新加坡也是备选。国内机房适合以后更重视大陆用户访问、且另设境外采集节点的阶段。

阿里云说明：使用中国内地主机提供网站服务涉及 ICP 备案，境外主机不需要该项备案；这不代表网站没有其他适用要求。参考：<https://www.alibabacloud.com/help/en/dns/icp-and-dns>。

出现持续内存压力、浏览器 OOM、采集队列增长或 API 延迟明显上升后，升级到 8GB 或拆分浏览器采集节点。首次采购不建议直接锁定长期套餐。
